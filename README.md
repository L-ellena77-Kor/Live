# 나만의 실시간 수업 (live.js)

Copyright 2026 엘레나

선생님 화면에서 6자리 수업 코드와 QR을 띄우고, 학생들이 크롬북·스마트폰으로 들어와
객관식 투표와 서술형 답을 실시간으로 보내는 수업 도구입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `live.js` | 엔진. 고칠 필요 없음 |
| `index.html` | 예시 수업(열평형). 이 파일을 복사해 문항만 바꾸면 새 수업 |
| `live-config.js` | (선택) 내 Supabase 공개 정보. 비워 둬도 됨 |
| `thermal.html` | 열팽창 13가지 시뮬레이션 + 실시간 질문 15개 |

## 처음 한 번: Supabase 준비

1. supabase.com에서 프로젝트를 하나 만듭니다. **테이블은 만들 필요가 없습니다.**
2. 프로젝트 설정 → API Keys 화면에서 두 가지를 복사합니다.
   - Project URL — `https://○○○○.supabase.co`
   - 공개 키 — `anon`(eyJ…로 시작) 또는 `sb_publishable_…`
3. **비밀 키(`service_role`, `sb_secret_…`)는 절대 쓰지 않습니다.** 넣으면 엔진이 거부합니다.
4. Realtime 설정에 "공개 채널 허용(Allow public access)" 같은 항목이 꺼져 있다면 켜 둡니다.

> 무료 프로젝트는 오래(약 1주) 안 쓰면 잠들 수 있어요. 수업 전날 Supabase 대시보드에서 깨어 있는지 확인하세요.

## 수업할 때

1. 선생님 컴퓨터에서 주소를 엽니다. 처음이면 ⚙ 설정에 주소·공개 키를 넣습니다(그 컴퓨터에만 기억).
2. QR 화면이 뜨면 학생들이 찍고 들어옵니다. 이름은 받지 않고, 반·번호는 학생이 원할 때만 적습니다.
3. **수업 시작 ▶** → 문항을 고르고 **▶ 학생에게 열기**. 다 받으면 **■ 마감하기**.
4. 객관식: 막대 결과, **결과 가리기**, **정답 공개**(학생 화면에도 정답 표시).
5. 서술형: 카드 오른쪽 위 ✕로 숨기기, 카드를 누르면 크게 보기(←/→로 넘기기).
6. 끝나면 **CSV 저장**. 엑셀·한글에서 한글이 깨지지 않게 저장됩니다.

키보드: ←/→ 문항 이동 · 스페이스 열기/마감 · F 전체화면 · Esc 닫기

## 새 수업 만들기

`index.html`을 복사해 이름을 바꾸고(예: `boyle.html`) 아래 부분만 고칩니다.

```js
Live.start({
  id: 'boyle-1',            // 수업마다 다르게
  title: '보일 법칙 생각 모으기',
  items: [
    { type:'choice', q:'질문', options:['보기1','보기2','보기3'], answer:1, img:'그림.png' },
    { type:'text',   q:'서술형 질문' }
  ]
});
```

## 시뮬레이션에 얹어 쓰기 (thermal.html)

- 선생님 화면: 시뮬레이션 위쪽 막대에 `[● 👥 코드]` `[📡 질문]` 단추가 생깁니다.
  - `[● 👥 코드]` → QR 화면 (처음이면 ⚙ 설정)
  - `[📡 질문]` → 실시간 창. **지금 보고 있는 쪽의 질문이 바로 나옵니다.**
  - 실시간 창의 **시뮬레이션으로 ✕** 또는 Esc → 다시 시뮬레이션
- 학생 화면: QR로 들어오면 시뮬레이션은 숨기고 문항만 보여 줍니다(크롬북 부담 줄이기).
- 다른 수업 페이지에 붙이려면 `</body>` 앞에 아래처럼 넣습니다.

```js
Live.start({
  embed: true,                 // 기존 페이지 위에 얹기
  mountBefore: '#fs',          // 이 단추 앞에 실시간 단추를 넣기 (없으면 오른쪽 아래에 떠 있음)
  pageOf: function(){ return 지금쪽번호; },   // (선택) 쪽마다 질문 연결
  items: [ { page:0, type:'choice', q:'…', options:[…], answer:1 } ]
});
```

## 안전·개인정보

- 학생 답은 Supabase **Realtime Broadcast로 주고받기만** 합니다. 데이터베이스 테이블을 쓰지 않으므로 서버에 저장되지 않습니다.
- 사진은 주고받지 않습니다.
- 모은 답은 선생님 컴퓨터 브라우저에만 남고, **새 수업 코드**를 누르면 지워집니다.
- 학생 링크의 서버 정보는 주소의 `#` 뒤에 담겨서 GitHub 서버로 전송되지 않습니다.
- 선생님 화면이 보내는 문항 신호에는 전자서명이 붙어 있어서, 학생이 F12로 가짜 문항을 보내도 QR로 들어온 다른 학생 화면은 바뀌지 않습니다.
- 서술형 카드에는 기본으로 반·번호를 띄우지 않습니다(⚙ 설정에서 켤 수 있음). CSV에는 들어갑니다.

## 연습 모드

⚙ 설정의 **연습 모드**를 누르면 인터넷 서버 없이 같은 컴퓨터의 브라우저 탭끼리만 주고받습니다.
QR 화면의 **학생 화면 새 탭으로 열기**로 미리 해 볼 수 있습니다.

## 알려진 한계

- 공개 키는 링크에 들어 있으므로, 링크를 가진 사람이 같은 수업 코드로 가짜 **답**을 보낼 수는 있습니다. 이상한 카드는 ✕로 숨기세요. (문항을 바꾸는 것은 서명 때문에 불가능)
- QR 대신 `주소#s`로 들어와 코드만 치는 방식(`live-config.js`를 채웠을 때)은 서명 확인을 하지 않습니다. 가능하면 QR을 쓰세요.
