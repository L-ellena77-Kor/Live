✅ 파일을 만들었어요

방금 내려받은 파일을 GitHub 저장소에 올리면 끝이에요.

  1. GitHub 저장소 첫 화면에서 Add file → Upload files
  2. 내려받기 폴더의 파일을 끌어다 놓기
  3. 아래 Commit changes 누르기
  4. 1~2분 뒤 📚 목록에 저절로 나타나요

같은 이름으로 다시 올리면 예전 파일이 새 내용으로 바뀌어요. 고칠 때는 📂 불러오기로 이 파일을 열면 돼요.
